# Download

The two finished programs. Download one, then double-click it. Don't use "Run as administrator".

| File | Use it on |
|---|---|
| `aiznm_CLEANER_Personal.bat` | **Your own PC.** Its System overview compares what Windows detects with your documented hardware (i9-10900F, PRIME B560-PLUS, 16 GB DDR4-3600, RTX 4060, Windows 10 Home 22H2). |
| `aiznm_CLEANER_Universal.bat` | **Any other Windows 10 or 11 PC.** Its System overview just shows the detected hardware with general hints. |

Apart from that one screen, both files are identical: same cleanup, safety rules, menus and logs.
Both are version 3.1.0.

See the main [README](../README.md) for the user guide.
