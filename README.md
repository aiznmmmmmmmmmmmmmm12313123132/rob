# rob

This repository holds two separate projects.

| Folder | Project |
|---|---|
| [`cleaner/`](cleaner/) | **aiznm CLEANER**: a safe storage-maintenance tool for Windows. The ready-to-run files are in [`cleaner/Download/`](cleaner/Download/). |
| `src/`, `tools/`, `docs/` | **Cartoon Dice**: the Roblox game (Luau scripts, Studio builder scripts and design notes). |

## aiznm CLEANER: quick download

| File | Use it on |
|---|---|
| [`aiznm_CLEANER_Personal.bat`](cleaner/Download/aiznm_CLEANER_Personal.bat) | The PC it was tailored for |
| [`aiznm_CLEANER_Universal.bat`](cleaner/Download/aiznm_CLEANER_Universal.bat) | Any Windows 10 or 11 PC |

To save one: open the file, click **Download raw file**, then double-click the `.bat`.
The user guide is in [`cleaner/README.md`](cleaner/README.md).
